**Subject**: [New Derivative Announcement] Omarchy for Ubuntu — Turnkey Hyprland Desktop OS

```text
Hello Ubuntu Derivatives Team,

I am pleased to announce the release of "Omarchy for Ubuntu", a new standalone Linux distribution based on Ubuntu LTS.

Project Overview:
Omarchy for Ubuntu combines the stability, hardware support, and package ecosystem of Ubuntu LTS with the fluid dynamics of the Hyprland Wayland compositor. It is packaged as a hybrid UEFI/BIOS bootable Live ISO image.

Key Features:
- Native Hyprland Wayland compositor with fluid Bezier animations
- Automated multi-monitor coordinate management and GUI controller (omarchy-displays-gui)
- Hardware-aware PipeWire audio routing with instant sink toggling
- Resilient systemd user daemon architecture with hardware readiness loops (waybar.service, swaybg.service)
- Dynamic 22-theme suite with live, zero-restart re-tinting across compositor, status bar, terminal, and menus
- Complete live boot environment with direct installer to disk

Links:
- Repository: https://github.com/apravint/omarchy-ubuntu
```
